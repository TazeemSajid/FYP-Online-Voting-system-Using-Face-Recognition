# FYP-Online-Voting-system-Using-Face-Recognition
**
📌 Overview**

This project is an online voting system that uses face recognition technology to ensure secure and authentic voting. The system verifies the identity of voters using facial recognition before allowing them to cast their vote, reducing the chances of fraud and duplicate voting.

**🎯 Objectives**

Develop a secure online voting system
Implement face recognition for voter authentication
Prevent duplicate and unauthorized voting
Ensure transparency and accuracy in the voting process

**🛠️ Tools & Technologies**

Python
OpenCV (Face Detection & Recognition)
NumPy
Face Recognition Library
Database (SQLite / MySQL)
Tkinter / Web Framework (if used)
⚙️ System Workflow

**1️⃣ User Registration**

Voters register by providing personal details
Facial data is captured and stored in the database

**2️⃣ Face Recognition Authentication**

During login, the system captures the user’s face
Matches it with stored facial data
Grants access only if identity is verified

**3️⃣ Voting Process**

Authenticated users can cast their vote
Each user is allowed to vote only once
System prevents duplicate voting

**4️⃣ Vote Storage & Results**

Votes are securely stored in the database
Results can be calculated automatically
Ensures transparency and accuracy

**🔐 Key Features**

Face recognition-based authentication
Secure and fraud-resistant voting system
One-person-one-vote mechanism
Automated vote counting
User-friendly interface
